## 🛠 نحوه نصب پوسته

برای نصب هر یک از تم‌ها، کافیست مراحل زیر را به ترتیب انجام دهید:

1.  **دانلود فایل تم:** از پوشه‌ی همان تم در همین مخزن، فایل `zip.` مربوطه را دانلود کنید.
2.  **آپلود در مسیر پوسته‌ها:** فایل `zip.` را در مسیر `usr/themes/` در نصب TypeRenew خود آپلود کنید.
3.  **استخراج (Extract):** فایل `zip.` را در همان مسیر استخراج کنید. پس از استخراج، یک پوشه با نام همان تم ایجاد می‌شود.
4.  **فعال‌سازی:** وارد پنل مدیریت TypeRenew شوید و به بخش **«کنترل پنل» → «ظاهر» (Appearance)** بروید.
5.  **انتخاب و استفاده:** تم مورد نظر خود را پیدا کرده و روی **«فعال‌سازی» (Activate)** کلیک کنید.

**نکته:** مطمئن شوید نام پوشه‌ی استخراج شده دقیقاً با نام تم (با حروف کوچک) یکسان باشد.

## 📂 ساختار مخزن

هر تم در یک پوشه‌ی مجزا قرار دارد و شامل دو فایل است:

```
TypeRenew-Themes/
├── ava/
│   ├── ava.zip              # فایل نصبی تم
│   └── screenshot.webp       # پیش‌نمایش تم
├── deltangi/
│   ├── deltangi.zip
│   └── screenshot.webp
├── elham/
│   └── ...
└── ...
```

- **فایل `zip.`** → فایل نصبی تم که می‌توانید مستقیماً در TypeRenew استفاده کنید.
- **فایل `screenshot.webp`** → تصویر پیش‌نمایش تم برای مشاهده‌ی سریع ظاهر آن.
